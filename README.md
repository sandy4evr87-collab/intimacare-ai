# IntimaCare AI 💜

**Your Personal Sexual Health & Wellness Companion**

A comprehensive health & wellness web application built with Flask, featuring AI-powered assistance, doctor consultations, diet plans, and more.

## 🌟 Features

- **🏠 Dashboard** - Track your daily mood, water intake, and health progress
- **💊 Sexual Health** - Personalized guidance for male & female wellness
- **🥗 Diet Charts** - Custom diet plans for Low Testosterone, PCOD, Low Libido
- **💧 Water Reminder** - Track your daily water intake with reminders
- **🧘 Stress Relief** - Meditation, breathing exercises, relaxing music
- **🧠 Mental Wellness** - Mood tracking, journaling, AI companion
- **🤖 AI Companion** - 24/7 chatbot for health queries
- **👨‍⚕️ Doctor Consultation** - Book appointments with verified sexologists
- **📱 Notifications** - Smart reminders for meals, water, and activities
- **👤 Profile Management** - Track your health journey
- **🔧 Admin Dashboard** - Manage users, doctors, and content

## 📦 Installation

### Prerequisites
- Python 3.11+
- pip

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/sandy4evr87-collab/intimacare-ai.git
   cd intimacare-ai
   ```

2. **Create virtual environment**
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   # source venv/bin/activate  # Mac/Linux
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the application**
   ```bash
   python app.py
   ```

5. **Open browser**
   ```
   http://127.0.0.1:5000
   ```

## 🌐 Deploy to Render (Free)

1. Push code to GitHub (done ✅)
2. Go to [render.com](https://render.com)
3. Sign up with GitHub
4. Click "New +" → "Web Service"
5. Select your `intimacare-ai` repo
6. Configure:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python app.py`
7. Click "Create Web Service"
